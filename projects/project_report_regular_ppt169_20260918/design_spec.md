# Design Specification & Content Outline

## I. Project
- Title: 中医诊前信息采集与整理系统
- Audience: 课题组组会与项目答辩
- Page count: 14
- Mode: briefing
- Style: standard academic defense deck

## II. Fixed Grid
- Cover is centered.
- Every content slide uses the same top-left title, divider line, content start, footer line, and page number.
- Permitted structures: equal two-column, upper-lower split, equal three-column, standard horizontal process, aligned table.

## III. Slide Roster
1. 封面
2. 项目背景与问题：左右双栏
3. 项目目标与定位：上下分区
4. 系统整体架构：四层等宽结构
5. 系统角色与主要功能：左右双栏加底部边界
6. 完整问诊流程：七步横向流程
7. 结构化字段与信息来源：左右双栏
8. 资料完整度如何判断：三栏判断结构
9. 追问优先级与决策机制：五行列表加底部示例
10. 何时停止追问：顶部判断加三列结果
11. 项目实现中的关键难点：四行三列表
12. 身份选择与患者端：左主图右双图
13. 问诊过程：三张等宽截图
14. 医生工作台与总结：上图下三列

## IV. Output
- Primary: editable native PowerPoint objects via Artifact Tool.
- Backup: image-based compatibility PPTX.
- Both outputs include 14 speaker notes.
