# 十问歌深度问诊指南

## 概述

本技能提供中医十问歌的深度追问框架。每次问诊按顺序覆盖以下维度，
每个维度先问主问题，再根据患者回答决定是否追问。

## 十问歌原文

> 一问寒热二问汗，三问头身四问便，
> 五问饮食六问胸，七聋八渴俱当辨，
> 九问旧病十问因，再兼服药参机变。
> 妇女尤必问经期，迟速闭崩皆可见。
> 再添片语告儿科，天花麻疹全占验。

## 逐项深度追问指南

### 1. 寒热

**主问题**：您平时是怕冷还是怕热？有没有发热的感觉？

**追问方向**：
- 恶寒发热同时出现 → 外感表证
- 只恶寒不发热 → 里寒证或阳虚
- 只发热不恶寒 → 里热证
- 午后潮热（下午定时发热）→ 阴虚潮热或湿热
- 手足心热 → 阴虚内热
- 手脚冰凉 → 阳虚或气血不足
- 上半身热下半身冷 → 上热下寒，阴阳失调

**记录要点**：发热时间、发热部位、冷热偏好、伴随症状

---

### 2. 汗出

**主问题**：您出汗多吗？有没有晚上睡觉出汗、或者稍微一动就大汗淋漓的情况？

**追问方向**：
- 白天不动也出汗（自汗）→ 气虚/阳虚
- 夜间睡着出汗醒来汗止（盗汗）→ 阴虚
- 稍微活动就大汗 → 气虚不固
- 局部出汗（如只有头出汗）→ 上焦热或湿热
- 手足心出汗 → 阴虚内热或脾胃湿热
- 半身出汗半身无汗 → 气血不和，中风先兆（⚠️ 红旗信号）
- 汗出如油、淋漓不止 → 危重症候（🚨 紧急就医）

**记录要点**：出汗时间、部位、量、诱因、伴随症状

---

### 3. 头身

**主问题**：有没有头痛、头晕？身体有没有哪里疼痛或者沉重感？

**追问方向**：

**头痛**：
- 胀痛 → 肝阳上亢
- 刺痛（固定位置）→ 血瘀
- 空痛/隐痛 → 气血亏虚
- 沉重如裹 → 痰湿蒙窍
- 随情绪加重 → 肝气郁结

**头晕**：
- 天旋地转 → 肝阳化风
- 头晕眼花、站起来加重 → 气血亏虚
- 头重如裹 → 痰湿中阻

**身体**：
- 全身沉重乏力 → 湿困脾土
- 固定部位刺痛 → 血瘀
- 游走性疼痛 → 风邪
- 腰膝酸软 → 肾虚

**记录要点**：部位、性质（胀/刺/空/重）、持续时间、诱因、缓解方式

---

### 4. 二便

**主问题**：大便和小便的情况怎么样？比如多久一次、成形还是稀的、颜色有没有异常？

**追问方向**：

**大便**：
- 便秘（干结如羊粪）→ 热秘或阴虚
- 便秘（排便无力）→ 气虚推动无力
- 溏泄（长期稀便）→ 脾虚
- 五更泻（天亮前腹痛腹泻）→ 肾阳虚
- 大便黏腻不爽→ 湿热
- 时干时稀 → 肝郁脾虚
- 便血（鲜红→近血/暗红→远血）→ ⚠️ 需就医排查

**小便**：
- 小便清长 → 虚寒
- 小便短赤（量少色深）→ 热证
- 夜尿频多 → 肾阳虚
- 小便涩痛 → 湿热下注
- 小便不禁 → 肾气不固

**记录要点**：频率、性状、颜色、气味、伴随感觉

---

### 5. 饮食

**主问题**：最近胃口怎么样？有没有偏好什么口味？喝水多不多？

**追问方向**：
- 食欲旺盛易饿 → 胃火亢盛
- 食欲不振（食后腹胀）→ 脾虚
- 饥不欲食（饿但不想吃）→ 胃阴虚
- 厌食油腻 → 肝胆湿热
- 口淡无味 → 脾虚
- 口苦 → 肝胆火旺
- 口甜/口腻 → 脾胃湿热
- 口干想喝冰水 → 实热
- 口干只想润口不欲咽 → 阴虚
- 口干不想喝水 → 湿阻中焦

**记录要点**：食欲、口味偏好、口渴程度、饮水冷热偏好、消化情况

---

### 6. 胸腹

**主问题**：胸口有没有闷的感觉？心慌心悸吗？肚子有没有胀气或者疼痛？

**追问方向**：
- 胸闷 → 气滞或痰阻
- 心慌心悸 → 心血不足或心阴虚
- 胃胀（饭后加重）→ 脾虚气滞
- 胃胀（嗳气后缓解）→ 肝胃不和
- 腹痛拒按 → 实证
- 腹痛喜按 → 虚证
- 胁肋胀痛 → 肝气郁结

**记录要点**：部位、性质、与饮食/情绪的关系

---

### 7. 睡眠

**主问题**：睡眠怎么样？是入睡困难、多梦、还是容易醒？

**追问方向**：
- 入睡困难 → 心火旺或肝火扰心
- 多梦纷纭 → 肝血不足或心脾两虚
- 易醒（凌晨1-3点）→ 肝经当令，肝气不畅
- 易醒（凌晨3-5点）→ 肺经当令，肺气不足
- 早醒后无法再睡 → 心肾不交
- 嗜睡、整天困倦 → 痰湿困脾或阳虚
- 噩梦频频 → 痰热扰心

**记录要点**：入睡时间、做梦情况、醒来时间、白天精神

---

### 8. 口渴与耳目

**主问题**：平时觉得口干口渴吗？耳朵听力、眼睛有没有不舒服？

**追问方向**：
- 口干想喝冰水 → 实热伤津
- 口干只想漱口不想吞咽 → 瘀血
- 不渴 → 寒证或湿证
- 耳鸣（如蝉鸣、持续）→ 肾精亏虚
- 耳鸣（如潮声、突发）→ 肝火上扰
- 目干涩 → 肝血不足
- 目赤肿痛 → 肝火上炎

**记录要点**：口干程度、饮水偏好、耳目症状

---

### 9. 旧病与服药

**主问题**：以前得过什么确诊的病吗？有没有慢性病？平时在吃什么药？

**追问方向**：
- 高血压/糖尿病/心脏病等慢性病史
- 手术史、外伤史
- 长期服药（西药、中药、保健品）
- 过敏史（药物/食物）
- 家族遗传病史

⚠️ 如果患者在服抗凝药、降糖药、降压药等，需关注相关禁忌。

**记录要点**：病名、确诊时间、当前用药（名称+剂量+频率）

---

### 10. 病因

**主问题**：这次不舒服大概是什么时候开始的？有没有什么明显的诱因？

**追问方向**：
- 外感：受凉/受热/淋雨/吹风
- 内伤：生气/焦虑/悲伤/压力大/熬夜/劳累
- 饮食：吃了什么东西后开始的
- 季节：什么季节容易发作
- 外伤：摔倒/碰撞后出现
- 无明显诱因 → 内伤杂病，需更详细的四诊

**记录要点**：发病时间、诱因、病程（急性/慢性/反复发作）

---

### 11. 女性经期（女性患者专项）

**触发条件**：患者为女性且年龄在12-55岁之间

**追问方向**：
- 周期：多少天来一次？规律吗？
- 经量：量多还是量少？有血块吗？
- 颜色：鲜红/暗红/淡红/紫暗？
- 痛经：经前痛还是经期痛？胀痛还是刺痛？
- 带下：量、色、气味如何？
- 是否绝经？何时绝经？绝经前后症状？

---

### 12. 舌象与脉象

**舌象**（如患者能提供）：
- 舌色：淡/红/绛/紫/暗
- 舌体：胖大/瘦薄/齿痕/裂纹
- 苔色：白/黄/灰/黑
- 苔质：薄/厚/腻/润/燥/剥落

**脉象**：标注为"待面诊采集"（因远程问诊无法切脉）

## 🚨 红旗信号（需建议立即就医）

出现以下任何症状，应在回复中温和建议患者尽快就医：

- 剧烈头痛伴呕吐、视力模糊 → 可能脑血管问题
- 胸痛彻背、大汗淋漓 → 可能心梗
- 突然半身麻木/无力/口眼歪斜 → 可能中风
- 高热不退（>39°C持续）→ 需排查严重感染
- 剧烈腹痛拒按 → 可能急腹症
- 呕血/便血/咯血 → 内脏出血
- 意识模糊/昏厥 → 需急诊

---

## 问诊技巧

1. **一次只问一个问题**，根据回答决定是否追问细节
2. **自然过渡**：从一个主题过渡到下一个时，用关联词衔接
3. **温和表达**：不用"你必须回答"，而用"方便说说吗"
4. **已提及则不重复问**：患者在其他话题中已提到的信息，引用确认即可
5. **注意隐私敏感话题**：经期、二便等问题需要更温和的语气
