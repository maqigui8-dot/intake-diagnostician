# 中医辨证速查表

> 供子智能体分析时参考。以下证型为临床常见类型，非完整列表。

---

## 一、八纲辨证速查

### 表证

| 证型 | 主症 | 舌象 | 典型提示 |
|------|------|------|----------|
| 表寒证 | 恶寒重发热轻、头痛身痛、无汗 | 苔薄白 | 外感风寒初期 |
| 表热证 | 发热重恶寒轻、咽痛口渴、有汗 | 舌尖红苔薄黄 | 外感风热 |
| 表虚证 | 恶风、自汗出、脉浮缓 | 苔薄白 | 卫气不固 |

### 寒热

| 证型 | 主症 | 舌象 | 典型提示 |
|------|------|------|----------|
| 实寒证 | 恶寒肢冷、腹痛拒按、面色苍白 | 舌淡苔白 | 寒邪直中 |
| 虚寒证（阳虚）| 畏寒喜暖、四肢不温、神疲乏力 | 舌淡胖苔白滑 | 阳气不足 |
| 实热证 | 高热口渴、烦躁、大便干结 | 舌红苔黄燥 | 热邪亢盛 |
| 虚热证（阴虚）| 午后潮热、手足心热、盗汗 | 舌红少苔 | 阴液亏虚 |

### 虚实

| 证型 | 主症 | 典型提示 |
|------|------|----------|
| 气虚证 | 神疲乏力、少气懒言、动则汗出 | 脾肺气虚最常见 |
| 血虚证 | 面色苍白、头晕眼花、心悸失眠 | 心肝血虚多见 |
| 阴虚证 | 口干咽燥、潮热盗汗、舌红少苔 | 肝肾阴虚多见 |
| 阳虚证 | 畏寒肢冷、神疲、小便清长 | 脾肾阳虚多见 |
| 气滞证 | 胀闷疼痛、部位不定、随情绪波动 | 肝气郁结最多见 |
| 血瘀证 | 刺痛固定、面色晦暗、舌有瘀斑 | 久病入络 |
| 痰湿证 | 胸闷脘痞、身重、苔腻 | 脾为生痰之源 |
| 水饮证 | 浮肿、小便不利、舌胖大 | 肺脾肾三脏失调 |

| 证型 | 主症 | 关键鉴别点 |
|------|------|------------|
| 气虚 | 神疲乏力、少气懒言、脉弱 | 全身功能减退 |

| 气滞 | 胀痛、攻窜不定、与情绪相关 | 不通则痛 |

## 四、病因病机速查

### 六淫辨证

| 病邪 | 致病特点 | 典型症状 |
|------|----------|----------|
| 风邪 | 善行数变、发病急、游走性 | 头痛游走、关节窜痛、皮疹此起彼伏、抽搐 |
| 寒邪 | 收引凝滞、伤阳气、疼痛 | 恶寒、肢体拘急冷痛、分泌物清稀 |
| 暑邪 | 炎热升散、耗气伤津、多夹湿 | 高热烦渴、多汗、神疲、胸闷呕恶 |
| 湿邪 | 重浊黏滞、易阻气机、迁延难愈 | 头身困重、脘痞纳呆、便溏、苔腻 |
| 燥邪 | 干燥涩滞、易伤肺津 | 咽干鼻燥、干咳少痰、皮肤干燥 |
| 火（热）邪 | 炎上灼津、迫血妄行、腐败成脓 | 高热面赤、出血、疮疡肿痛 |

## 五、复合证型提示

临床常见多种证型同时存在，分析时注意：

- **肝郁脾虚** = 胁肋胀痛 + 食少便溏（最常见复合证型之一）
- **心肾不交** = 心烦失眠（心火旺）+ 腰膝酸软（肾阴虚）
- **脾肾阳虚** = 五更泻 + 腰膝冷痛
- **气阴两虚** = 神疲乏力 + 口干盗汗
- **痰瘀互结** = 胸闷 + 刺痛 + 苔腻 + 舌紫暗
- **肝阳上亢** = 头胀痛 + 腰膝酸软（上盛下虚）
- **上热下寒** = 口舌生疮 + 下肢冰凉

## 使用说明

子智能体进行辨证分析时：
1. 先用八纲辨证定大方向（寒热虚实表里阴阳）
2. 再用脏腑辨证定位病变脏腑
3. 用气血津液辨证分析物质基础
4. 最后用病因病机辨证推断病因
5. 输出格式：病位 + 病性 + 核心病机 + 最可能的证型 + 追问建议
