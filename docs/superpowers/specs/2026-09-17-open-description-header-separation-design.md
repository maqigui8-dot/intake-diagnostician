# 开放描述页标题分区设计

## 目标

将开放描述页中“医 / 开放描述”与“先从您最关心的情况说起 / 不需要使用医学术语……”拆成上下两个视觉区块，明确阶段标识与正文提问的层级。

## 设计

- 上方身份区只保留圆形“医”标识和“开放描述”阶段标签。
- 下方正文区单独承载主标题、说明文字、回答输入框和提交操作。
- 两个区域使用间距和细分隔线建立联系，不增加额外图标或装饰。
- 仅修改开放描述首屏，不改变基础资料、补充问诊、结果页和任何业务逻辑。

## 验收标准

- “医 / 开放描述”与主标题不再处于同一内容组。
- 主标题和说明文字仍保持原文。
- 桌面端与移动端均保持清晰层级，无横向溢出。
