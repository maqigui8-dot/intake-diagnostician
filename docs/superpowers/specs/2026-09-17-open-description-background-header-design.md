# 开放描述页背景化标题设计

## 目标

将“医 / 开放描述 / 先从您最关心的情况说起 / 不需要使用医学术语……”从白色内容卡片中移出，直接融入浅绿色页面背景；具体问题与输入操作保留在独立白色卡片中。

## 页面结构

- `.open-intake` 改为无背景、无边框、无阴影的页面容器。
- `.open-intake-header` 承载身份标识、阶段标签、标题和说明，直接显示于页面背景。
- `.open-question` 成为独立白色卡片，承载具体问题、文本框、提示和按钮。
- 标题区与输入卡片之间保留约 24px 自然留白，不使用明显分割线。

## 约束

- 所有现有文案保持不变。
- 不增加新图标和装饰。
- 不改变提交、校验与问诊流程逻辑。
- 桌面端和移动端均不得横向溢出。

## 验收标准

- 顶部介绍区视觉上属于浅绿色页面背景，而非白色卡片。
- 白色卡片从具体问题开始。
- 输入框、按钮和键盘操作保持正常。
