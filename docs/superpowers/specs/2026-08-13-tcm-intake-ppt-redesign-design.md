# 中医诊前问诊系统汇报 PPT 重做设计

## 目标

使用用户提供的 5 张项目实机截图，重新制作一份 7 页中文进展汇报。汇报重点按“原来的问题 → 主要改进 → 当前完整使用流程 → 各阶段实机页面 → 最终产出”展开，不以代码细节和测试数字作为主线。

## 页面结构

1. 封面：中医诊前问诊系统阶段改进。
2. 原来存在的问题：追问不是连续聊天式、回答后需要刷新或重新进入、内部完整度判断暴露给用户、页面内容不够聚焦。
3. 主要改进：对话式追问、无需刷新、保留历史、隐藏不必要内容；使用图 1。
4. 当前完整使用流程：10 个基础必问项 → 完整度判断 → 对话式追问 → 诊前档案 → 推荐检查。
5. 第一阶段：10 个基础必问项；使用图 2，并说明 `tcm-intake-checklist` 的作用。
6. 第二阶段：对话式追问；使用图 3，并说明 `tcm-questioning-guide`、稳定缺口 key、去重和 12 轮安全保护。
7. 最终输出：完整诊前档案和推荐检查项目；使用图 4、图 5。

## 视觉设计

- 画布：16:9，1280 × 720。
- 风格：延续项目的白底医疗绿、轻量圆角和克制留白。
- 图片：全部按原比例显示，不裁切关键信息，不拉伸。
- 字体：微软雅黑，适配 Windows 和现场投影。
- 图标：统一使用 `tabler-outline`，只用于辅助识别。
- 用户可见文案不出现“缺失必问项”和“建议选问项”等内部界面字段；这些概念只在汇报解释中说明其已被隐藏。

## 成功标准

- 7 页顺序与确认方案一致。
- 5 张截图均清晰可辨，且各只承担一个阶段的主要说明。
- 第 4 页能一眼看清完整闭环。
- 第 6 页说明对话式追问如何避免刷新、重复追问和无限轮次。
- SVG 根元素均包含 `width="1280"`、`height="720"`、`viewBox="0 0 1280 720"`。
- 质量检查 0 错误，逐页视觉检查无溢出、遮挡和异常裁切。
