## 左侧内容

工作链路：

患者输入 → 查询历史 → 辨证分析 → 保存记录 → 生成对比报告

实现要点：

1. 使用 `create_deep_agent` 统一配置模型、工具、系统提示词和会话状态。
2. 通过 `get_patient_history`、`retrieve_knowledge` 和 `save_session_and_respond` 完成历史查询、知识检索与记录保存。
3. 使用 `SqliteSaver` 保存会话状态；诊疗记录支持 PostgreSQL，并在不可用时回退到 SQLite。
