# 主内容区垂直位置微调设计

## 目标

将桌面端中央主内容整体向下移动约 30px，使首屏留白更舒展；左侧固定侧栏保持原位。

## 设计

- 桌面端增加 `.main-workspace` 的顶部内边距，由 `40px` 调整为 `70px`。
- 水平间距、内容宽度、侧栏位置和折叠行为均不改变。
- `860px` 以下移动端继续使用现有 `76px` 顶部间距，避免顶部悬浮按钮遮挡内容。
- 医生模式沿用同一主工作区偏移，保持两种视图一致。

## 验收标准

- 桌面端主卡片相较当前版本下移约 30px。
- 侧栏仍贴左、全高且不发生位移。
- 折叠侧栏后主内容横向布局正常。
- 移动端顶部间距保持不变。
